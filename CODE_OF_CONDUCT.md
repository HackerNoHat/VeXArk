# Code of conduct

VeXArk uses the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its community standard.

Be respectful, assume good intent and keep technical disagreement focused on the
work. Harassment, discrimination, publication of private information and
deliberately unsafe advice are not accepted.

Project maintainers may remove, edit or reject contributions and interactions
that violate these expectations. Serious or repeated violations can result in a
temporary or permanent ban from project spaces.

Report conduct issues privately to the repository owner. Do not use public issues
when a report contains personal or sensitive information.
