# VeXArk 0.8.0-beta.4 — rooted backup diagnostics and safe cancellation

This prerelease makes rooted Android backups observable, recoverable and safe
to interrupt.

## Highlights

- **Cancel copying:** cancel an active encrypted backup, Android/iPhone media
  copy or restore from the persistent status panel.
- **Atomic backup cancellation:** an interrupted backup never publishes an
  incomplete snapshot; chunks already written remain reusable.
- **Resumable Android media:** completed files remain in place and the current
  `.vexark.part` file resumes on the next run.
- **KernelSU diagnostics:** follow ADB → Agent → pairing → `root_request`, with
  shell/helper UID, provider, exit codes and safe error details.
- **Side-by-side Dev channel:** `VeXArk Dev` and `VeXArk Agent Dev` use separate
  settings, package `com.vex.phonebackup.agent.dev` and port `49322`.
- **Strict Agent preflight:** root operations stop on a channel, package,
  protocol, version, build ID or embedded-APK mismatch.
- **Offline support bundle:** export redacted Desktop/Agent logs and safe device
  properties locally; nothing is sent automatically.

## Fixes in beta.4

- Production APK certificate verification hashes the signer PEM certificate
  directly and no longer depends on localized `apksigner` output.
- Desktop cancellation tests run on clean Windows CI without a local `adb.exe`.
- The release build runs diagnostics tests under the required Dev profile, then
  publishes the separately built Stable application.
- Root socket handling, FIFO helper streaming, signed-JSON canonicalization,
  independent protocol connections and cancellation cleanup include the fixes
  introduced in beta.2.

## Validation

- Xiaomi `24129PN74G`, Android 16 custom ROM and KernelSU returned UID 0 from
  both the root shell and native helper.
- Full encrypted backup: 301 components and 23,577 / 23,577 referenced objects
  verified.
- MediaStore export: 574 files, 19.31 GiB, zero failed files.
- A second physical-disk mirror passed full repository verification.
- Local tests: 39 Core, 21 Desktop and 7 Android tests.

Cross-ROM restore remains conservative. Android Keystore/TEE credentials,
Wallet and DRM tokens, eSIM data and hardware-bound passkeys are not portable
and must be provisioned again.

## Русский

- Во время backup, копирования медиа с Android/iPhone и Restore доступна кнопка
  **«Отменить копирование»**.
- Незавершённый snapshot не публикуется, уже записанные chunks переиспользуются,
  а текущий Android-медиафайл продолжится из `.vexark.part`.
- Добавлены сквозной Root test, отдельный Dev Agent, строгий preflight версий,
  структурированные логи и локальный support bundle без автоотправки.
- Исправлены root-crash, смешивание протокольных кадров и возврат приложений из
  `force-stop` после отмены.
- APK Stable проверяется по SHA-256 самого PEM-сертификата до публикации.

Проверено на Xiaomi `24129PN74G` с Android 16 и KernelSU: UID 0, полный snapshot
из 301 компонента, 23 577 / 23 577 объектов и 574 медиафайла объёмом 19,31 ГиБ.
