# VeXArk 0.8.0-beta.1 — iPhone media import preview

This prerelease adds direct photo and video copying from an iPhone to the
portable Windows client. It is intentionally marked beta until the complete
workflow is validated across physical iPhones, iOS versions and large libraries.

## Highlights

- **No iPhone app:** VeXArk uses the native Windows media-import APIs.
- **Original media:** imports photos, HEIC files, videos and Live Photo
  companions.
- **Folder structure:** preserves the original DCIM hierarchy.
- **Incremental import:** Windows marks previously imported items so subsequent
  runs select only new media.
- **Safe source:** VeXArk never calls the API that deletes imported items from
  the iPhone.
- **Live feedback:** the Desktop UI reports scan progress, item counts,
  transferred bytes, speed and estimated remaining time.
- **Android unchanged:** existing ADB and encrypted Fast Wi-Fi media exports
  remain separate.

## Before testing

1. Install Apple Devices from the Microsoft Store.
2. Connect the iPhone over USB, unlock it and approve **Trust This Computer**.
3. Open **Photos & videos**, select **Find iPhone**, choose a destination and
   select **Copy from iPhone**.

If iCloud Photos uses optimized storage, download the full-resolution originals
to the iPhone before importing.

## Validation

- Windows Release build and self-contained single-file publish completed with
  no warnings or errors.
- All 38 Core tests passed.
- The native media-import discovery path was exercised from the unpackaged
  portable WPF application.
- Physical iPhone transfer is not claimed as complete validation in this beta.

Please report the iPhone model, iOS version, Windows version and whether iCloud
optimized storage is enabled when filing import issues.

## Русский

Этот prerelease добавляет прямое копирование фото и видео с iPhone в portable-
клиент VeXArk для Windows. Версия помечена как beta до проверки полного сценария
на разных моделях iPhone, версиях iOS и больших медиатеках.

### Главное

- Приложение на iPhone не требуется: используется системный импорт Windows.
- Копируются оригиналы, HEIC, видео и компоненты Live Photos.
- Сохраняется исходная структура DCIM.
- При повторном запуске выбираются только новые медиа.
- VeXArk не вызывает удаление импортированных файлов с iPhone.
- В интерфейсе показываются прогресс, объём, скорость и оставшееся время.
- Существующий экспорт Android через ADB и Fast Wi-Fi не изменён.

### Как проверить

1. Установите Apple Devices из Microsoft Store.
2. Подключите iPhone по USB, разблокируйте его и подтвердите «Доверять этому
   компьютеру».
3. Откройте «Фото и видео», нажмите «Найти iPhone», выберите папку и нажмите
   «Скопировать с iPhone».

Если iCloud Photos оптимизирует хранилище, сначала загрузите оригиналы полного
разрешения на iPhone.
