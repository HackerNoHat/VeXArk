# VeXArk 0.8.0-beta.2 — rooted backup diagnostics and safe cancellation

This prerelease focuses on making rooted Android backups observable, recoverable
and safe to interrupt.

## Highlights

- **Cancel copying:** an active backup, Android/iPhone media copy or restore can
  be cancelled from the persistent status panel.
- **Atomic backup cancellation:** an interrupted encrypted backup never publishes
  a partial snapshot. Chunks already written remain deduplicated and reusable.
- **Resumable Android media:** completed files stay complete and the current
  `.vexark.part` file resumes on the next run.
- **KernelSU diagnostics:** Desktop shows the complete ADB → Agent → pairing →
  `root_request` chain, including shell/helper UID, provider, exit codes and
  safe error details.
- **Side-by-side Dev channel:** `VeXArk Dev` and `VeXArk Agent Dev` use their own
  identity, settings, package (`com.vex.phonebackup.agent.dev`) and port (`49322`).
- **Strict Agent preflight:** root operations are blocked when channel, package,
  protocol, version, build ID or embedded APK hash do not match.
- **Encrypted failure report:** transient live-file failures no longer discard
  the rest of a snapshot and are recorded in `backup-failures.json`.
- **Offline support bundle:** structured Desktop/Agent logs, safe device
  properties and filtered Logcat can be exported locally with secret redaction.

## Important fixes

- Replaced the libsu callback stream that could write to a socket on Android's
  main thread and crash Agent.
- Root scan/read now use a FIFO-backed native-helper stream with safe broken-pipe
  handling.
- Desktop and Android now sign the same platform-independent canonical JSON.
- Independent control, scan and read connections prevent protocol-frame
  interleaving.
- Cancelling a package operation still releases `force-stop` state and abandons
  incomplete Android install sessions.

## Validation

- Xiaomi `24129PN74G`, Android 16 custom ROM, KernelSU: root shell and helper both
  returned UID 0.
- Full encrypted backup: 301 components and 23,577 / 23,577 referenced objects
  verified.
- MediaStore export: 574 files, 19.31 GiB, zero failed files.
- A second physical-disk mirror passed full encrypted-repository verification.
- 39 Core tests, 21 Desktop tests, Android unit tests and a local Dev build.
- The signed stable bundle is built by GitHub Actions; the build now rejects an unexpected stable signing certificate.

Full restore across different ROMs remains intentionally conservative. Android
Keystore/TEE credentials, Wallet tokens, DRM keys, eSIM and hardware-bound
passkeys are not portable and must be provisioned again.

## Русский

Этот prerelease делает root-backup диагностируемым, возобновляемым и безопасным
для ручной отмены.

### Главное

- Во время backup, копирования медиа с Android/iPhone и Restore появляется
  кнопка **«Отменить копирование»**.
- При отмене незавершённый snapshot не публикуется. Уже записанные
  дедуплицированные chunks используются при следующем запуске.
- Готовые медиафайлы сохраняются, текущий файл Android продолжится из
  `.vexark.part`.
- Добавлены сквозной Root test, отдельный Dev Agent, строгий preflight версий,
  структурированные логи и локальный support bundle без автоматической отправки.
- Ошибки чтения живых root-файлов записываются в зашифрованный
  `backup-failures.json`, а остальной snapshot продолжает создаваться.
- Исправлен Android-crash `NetworkOnMainThreadException`, смешивание
  протокольных frames и возврат приложений из `force-stop` после отмены.

Проверено на Xiaomi `24129PN74G` с Android 16 и KernelSU: shell/helper UID 0,
полный snapshot из 301 компонента, 23 577 / 23 577 проверенных объектов и
574 медиафайла объёмом 19,31 ГиБ.

При восстановлении на другую ROM аппаратно привязанные ключи Android Keystore,
Wallet/DRM, eSIM и passkeys необходимо настроить заново.
