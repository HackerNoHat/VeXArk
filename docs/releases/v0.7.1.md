# VeXArk 0.7.1 — Connection tester

VeXArk 0.7.1 adds a built-in way to test USB cables, motherboard ports, ADB
and encrypted Fast Wi-Fi before starting a large transfer.

## Highlights

- **Negotiated USB link:** the Windows client reports whether the connected
  phone is actually using Low, Full, High, SuperSpeed or SuperSpeedPlus.
- **USB 2 fallback warning:** VeXArk highlights when a USB 3-capable phone has
  negotiated only the 480 Mbit/s High-Speed mode.
- **Real throughput:** a 256 MiB generated stream measures ADB and Fast Wi-Fi
  without opening photos, videos or other personal files.
- **Integrity checked:** every probe is validated with SHA-256.
- **Clear recommendation:** the client recommends ADB or Fast Wi-Fi and
  estimates transfer time for 10, 50 and 100 GiB.
- **No test artifacts:** the benchmark does not create a temporary media file
  on the phone or computer.

## Validation

The release build was validated on a Xiaomi 15 with a custom ROM. With a USB
2.0 cable, Windows correctly reported High-Speed and VeXArk measured about
39.4 MiB/s through ADB. Encrypted Fast Wi-Fi measured approximately
50–58 MiB/s under the tested network conditions and was recommended
automatically.

Throughput depends on the cable, USB controller, phone, access point and
computer. A cable's charging wattage does not indicate its data speed.

## Русский

VeXArk 0.7.1 добавляет встроенный тест кабелей, USB-портов, ADB и
зашифрованного Fast Wi-Fi перед большим копированием.

Windows-клиент показывает физически согласованный режим USB и предупреждает,
если телефон с поддержкой USB 3 подключился только в режиме High-Speed
480 Мбит/с. Затем VeXArk передаёт 256 МиБ сгенерированных данных через ADB и
Fast Wi-Fi, проверяет SHA-256, рекомендует быстрый транспорт и рассчитывает
время для 10, 50 и 100 ГиБ.

Тест не читает фотографии, видео и другие личные данные и не оставляет
временных файлов. На Xiaomi 15 с USB 2.0 кабелем было измерено около
39,4 МиБ/с через ADB и 50–58 МиБ/с через Fast Wi-Fi.
