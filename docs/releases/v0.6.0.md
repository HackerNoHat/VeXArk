# VeXArk 0.6.0 — themes, languages and public project launch

VeXArk 0.6.0 turns the working backup prototype into a coherent bilingual
product release.

## Highlights

- System, Light, Dark and true-black OLED Windows themes.
- English UI by default with English/Russian selection.
- Material You Android Agent with an in-app language selector.
- New VeXArk identity across EXE, APK, launcher icon and portable `.vexark` files.
- Bilingual documentation and GitHub Pages landing page.
- Automated build, release and checksum workflows.

## Downloads

- `VeXArk.exe` — portable Windows 10/11 x64 client.
- `VeXArk-Agent.apk` — Android 10–16 arm64 Agent.
- `SHA256SUMS.txt` — checksums for both files.

## Important

This is a pre-1.0 release. The no-root media/APK pipeline and encrypted repository
are the most mature paths. Rooted app-data and Controlled Full restore still need
broader testing across devices and ROMs. Keep an independent copy of critical data.
